Removes every appearance of every kind - face, feature, body, part and component - from every display state and every configuration.
In an assembly it also clears the appearances held inside every part file it references, so a part used elsewhere is changed there too.
Nothing is saved to disk: the modified documents are left unsaved, so closing without saving reverses the whole run.
Suppressed and lightweight components are resolved first. Asks for confirmation before running. There is no undo.
